# SIDA Project

A sample HTML/CSS/JavaScript project created as a practice project for learning how to publish a website on **GitHub** and make it accessible online using **GitHub Pages**.

## 🌐 Live Demo

**GitHub Pages:**
[Sida Sample Hosting URL](https://frost-as.github.io/Sida-Sample/)

## 📌 About

This project was created to practice:

* Building a website with HTML, CSS, and JavaScript
* Organizing a web project
* Using Git and GitHub
* Creating commits and pushing changes to GitHub
* Deploying a static HTML website with GitHub Pages

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Bootstrap Icons
* Git
* GitHub
* GitHub Pages

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Navigate into the project:

```bash
cd YOUR-REPOSITORY
```

Then open `index.html` in your browser.

You can also use **VS Code + Live Server** for local development.
